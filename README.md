# Temas Drupal - [datos.gob.es](https://datos.gob.es/)

Se incluyen en esta sección los *themes* desarrollados para el proyecto, que deben integrarse en Drupal según el modelo de despliegue definido.

Estos *themes* proporcionan la capa de presentación y estilos necesarios para la integración con el portal datos.gob.es.

> [!TIP]
> Para más información el repositorio base está disponible en [github.com/datosgobes/datos.gob.es](https://github.com/datosgobes/datos.gob.es)

### Dependencias

Requiere [Drupal versión 10.x](https://www.drupal.org/project/drupal/releases?version=10)

### Instalación

El proceso de instalación debe seguir el modelo de despliegue de Drupal para *modules* *contrib*, activación de *features* e integración de *themes*, aplicando las recomendaciones de su [documentación oficial](https://www.drupal.org/docs/). Para cualquier consulta, puede utilizar el [punto de contacto](https://datos.gob.es/es/form/contact) de datos.gob.es.


## Themes

| Extensión | Nombre | Descripción |
|---|---|---|
| `dge_admin_theme` | DGE admin theme | Extensión del *theme* Claro |
| `dge_theme` | DGE Custom Theme | *Theme* corporativo personalizado para datos.gob.es |
| `sendmail` | Sendmail | *Theme* para personalizar *emails* |

Si descubres una vulnerabilidad de seguridad, no la reportes públicamente a través de *issues*. En su lugar, consulta la [Política de Seguridad](https://github.com/datosgobes/datos.gob.es/blob/master/SECURITY.md) para obtener instrucciones sobre cómo reportarla de forma responsable.
